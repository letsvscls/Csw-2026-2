# Landing page

Páginas: index.html, curriculo.html, github.html, servicos.html, contato.html

## Publicar no GitHub Pages
1. Crie um repositório público no GitHub.
2. Envie todos os arquivos desta pasta (mantendo as pastas css, img e audio).
3. Em Settings > Pages, escolha Deploy from a branch > main > / (root) > Save.
4. O link será https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/

## O que trocar
- "Seu Nome", "SEU-USUARIO", e-mail e telefone
- img/foto.svg por sua foto (e ajuste o src nas páginas)
- audio/minha-musica.mp3 (coloque seu áudio)
- VIDEO_ID do YouTube em index.html
- SEU_ID do Formspree em contato.html
